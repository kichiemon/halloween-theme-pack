# Security Policy

## Supported Versions

We provide security updates and patches for the current major release:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Halloween Theme Pack team takes security seriously. If you discover a security vulnerability in this repository, please report it responsibly rather than opening a public issue.

### How to Report

Please report security issues privately via:
- **Email:** [kichiemon.dev@gmail.com](mailto:kichiemon.dev@gmail.com)
- **GitHub:** Use the private [Report a vulnerability](https://github.com/kichiemon/halloween-theme-pack/security/advisories/new) tab under Security Advisories.

### What to Include

Please provide as much relevant information as possible, including:
1. Description of the vulnerability.
2. Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
3. The potential impact (e.g., path traversal, script injection in terminal configs).
4. Any proposed fixes or mitigations.

### Response Timeline

- **Initial Response:** Within 48 hours acknowledging receipt of your report.
- **Assessment & Status:** Updates provided within 5 business days with triage results.
- **Resolution:** A patch will be published as a release as soon as possible after fix verification.

## Security Considerations

- **Static Theme Files:** Theme files generated by `generate.py` are static text, JSON, YAML, TOML, or CSS configs. They should never include dynamic code evaluation or remote script execution.
- **Installer Scripts:** Scripts such as `install.sh` and `bin/install-skill.js` write only to standard user-level config directories and do not execute untrusted external code without verification.
