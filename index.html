Quick Start

Install in Seconds

Choose your favorite installation method — automated CLI, interactive wizard, or direct file import.

Auto-detects all installed applications on your machine and places configs in their appropriate paths:

# Clone repository and run auto-apply git clone https://github.com/kichiemon/halloween-theme-pack.git cd halloween-theme-pack ./bin/halloween-gen apply # Options: choose variant or dry-run without modifying files ./bin/halloween-gen apply --variant oled ./bin/halloween-gen apply --dry-run

Interactive CLI step-by-step picker to choose your preferred variant and individual apps:

# Run interactive installer ./bin/halloween-gen install # Pick variant directly with custom selection ./bin/halloween-gen install --variant cyberpunk

Re-generate all theme files and run WCAG automated contrast tests from source:

# Generate 200+ theme files into ./themes/ python3 generate.py # Validate contrast ratios, hex values, and syntax python3 validate.py

Directly copy theme files from the themes/ directory into your app's config directory:

# Ghostty cp themes/terminal/halloween.ghostty ~/.config/ghostty/themes/halloween # K9s Kubernetes Skin cp themes/terminal/halloween.k9s.yaml ~/.config/k9s/skins/skin.yaml # Yazi File Manager cp themes/terminal/halloween.yazi.toml ~/.config/yazi/theme.toml

Test & Customize Live in Your Browser

Experience our full theme studio: test ANSI colors, inspect real-time WCAG contrast scores, and simulate colorblind vision modes (Deutan, Protan, Tritan). Zero setup required.
