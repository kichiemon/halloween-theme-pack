# Orca Halloween Theme

A Halloween-themed color set for Orca (stablyai/orca).

![Preview](assets/preview.png)

## Files

- `halloween.yaml` — Terminal theme in Warp custom-theme format. Importable into
  Orca via **Settings → Appearance → Terminal → Import from YAML** (or
  "Choose Folder" pointing at this directory).
- `halloween.css` — App UI theme (chat UI, sidebars, panels, popovers) as CSS
  custom-property overrides. Requires Orca's early-access app-theme feature
  (stablyai/orca discussion #25456); otherwise apply manually.

## Palette

- Background: `#1a0d2e` (deep purple night)
- Foreground: `#f4e7d3` (bone)
- Accent / pumpkin: `#ff6b35`
- Blood red: `#ff4d6d`
- Slime green: `#7fff6b`
- Witch purple: `#c77dff`
- Spooky cyan: `#5ffbf1`
